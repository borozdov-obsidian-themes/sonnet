# Borozdov Sonnet

A theme from the Borozdov collection. Two faces — light **Page**, a writer's studio on
pastel paper, and dark **Inkwell**, the same studio after dark. A quiet grayscale canvas,
one warm serif headline, a dusk-coloured wash over the side panels and a pink-to-lavender
gradient for what you act on.

![Borozdov Sonnet in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/sonnet/main/screenshots/light.png)

![Borozdov Sonnet in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/sonnet/main/screenshots/dark.png)

## Principles

- **Serif poetry.** Alegreya, a serif drawn for literature, for the title, the two largest
  headings and pull quotes; the platform's own sans, modest and quiet, for everything else.
- **One gradient.** Pink bleeding into lavender is the only emotional colour: it washes the
  side panels, fills a checked task and a toggle, underlines every link, tints the
  highlighter and glows around the main button. Everything else is grayscale.
- **Lagoon for labels.** Tags and property values are cool teal pills with ink text — the
  one categorical colour on a sea of grey.
- **Soft cards.** Callouts, embeds and panels are white with a fog hairline, 20px corners
  and a whisper of lift.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Links underlined by the gradient; the line thickens on hover
- Pull quotes in the serif, a size up, behind a gradient rule
- The open file in the sidebar sits in a wash of the gradient
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Sonnet**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/sonnet/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Sonnet/`, then choose Borozdov Sonnet under
Settings → Appearance → Themes.

## Font

Alegreya Medium (© 2011 The Alegreya Project Authors) is embedded in `theme.css` as base64
WOFF2 under the SIL Open Font License 1.1 — see [`fonts/OFL.txt`](fonts/OFL.txt). One
weight, Latin and Cyrillic, for the title, the two largest headings and pull quotes only.
